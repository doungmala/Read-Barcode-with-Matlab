# Read-Barcode-with-Matlab

Read Barcode with MATLAB

A simple and effective MATLAB project for detecting, localizing, and decoding 1-D barcodes and 2-D QR codes using image processing and Computer Vision Toolbox.

Features

1-D & 2-D Barcode Support: Detects and decodes standard linear barcodes (e.g., EAN-13, Code 39) and matrix codes (QR Code). Image Preprocessing: Grayscale conversion, noise reduction, and thresholding techniques. Visualization: Highlights barcode locations, bounding boxes, and displays decoded messages directly on the image.
